Do not describe the repository as an official 3-5 Power Electronics, Microsoft, or Mozilla Thunderbird product.

Leave the repository homepage empty or use a future dedicated project page. Do not use `https://3-5pe.com/` as the repository homepage unless the company explicitly hosts or officially supports this open-source project.

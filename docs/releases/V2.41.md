# M365 Calendar for Thunderbird V2.41

Release date: 2026-09-24

## Thunderbird 154+ / 156 compatibility

- Fixed native-calendar activation hanging on Thunderbird 154+ after removal of the legacy `CalStartupService` / `calendar-startup-done` startup mechanism.
- Current Thunderbird releases now initialize the Calendar Manager through its lazy `getCalendars()` / `assureCache()` path.
- Retains the legacy startup-service path for older supported Thunderbird releases where it is still available.
- Added a bounded legacy-startup timeout so a missing startup notification cannot block the Experiment forever.
- Added bounded Settings diagnostics calls so `Native provider: checking...` and `Diagnostics: Loading...` fail with an explicit error instead of hanging indefinitely.
- Added regression coverage for the Thunderbird 154+ startup path.

Microsoft Graph synchronization semantics and OAuth configuration are otherwise unchanged from V2.40.

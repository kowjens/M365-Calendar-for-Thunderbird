# V2.42

V2.42 improves handling of **external iMIP invitations** that Thunderbird receives before a matching Exchange event is available.

## Changes

- Adds an explicit NATIVE setting: **External email invitation fallback (iMIP → personal M365 copy)**. It is disabled by default in public builds.
- If a matching Exchange/Graph event already exists, the normal Graph RSVP path remains authoritative.
- If no matching Exchange event exists and the fallback is enabled, the NATIVE provider can create a personal Microsoft 365 calendar copy without recreating the original attendee list, while Thunderbird sends the RSVP through the receiving mail identity.
- Adds detailed Microsoft Entra application-registration documentation.
- Retains the Thunderbird 154+/156 native calendar startup fix from V2.41.

## Compatibility

- GitHub NATIVE: no strict maximum
- ATN NATIVE: validated Experiment maximum supplied during packaging
- STANDARD: no Experiment API

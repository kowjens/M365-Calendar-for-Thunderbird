# V2.49

**Version:** 2.0.49 / V2.49  
**Date:** 2026-09-25

V2.49 is an ATN review-hardening release. Calendar runtime behavior is intentionally kept aligned with V2.48, including the native diagnostics used to document the Thunderbird Month/Multiweek rendering limitation.

## Changes

- Reworked `runtime.onMessage` registration so the listener itself is synchronous and only keeps the response channel open for messages handled by this add-on.
- Reformatted settings JavaScript and CSS into directly reviewable source; the shipped ATN package is no longer intentionally compact/minified.
- Removed `browser.nativeCalendar` references and native-only controls from STANDARD/ATN source. The native Experiment remains exclusive to NATIVE builds.
- Added an explicit Microsoft Graph / Microsoft identity data-transfer disclosure to settings and publishing documentation.
- Kept the `sensitiveDataUpload` permission intentionally because user-requested Microsoft 365 features exchange calendar/invitation/contact data with Microsoft services. The extension has no developer-operated telemetry or data backend.
- Preserved direct GitHub repository update support from V2.43 and later.

## Known Thunderbird issue

The NATIVE edition can expose a Thunderbird Month/Multiweek frontend rendering issue where items are present in Graph, native cache/provider queries and the Thunderbird calendar DOM but are not visibly painted in Month/Multiweek. Day/Week can still show the same items. See `docs/KNOWN_ISSUES.md`.

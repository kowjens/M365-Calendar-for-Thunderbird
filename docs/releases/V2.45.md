# M365 Calendar for Thunderbird V2.45

V2.45 is a release-engineering and quality-assurance update built on the tested V2.44 runtime. Calendar, Microsoft Graph and native-provider behavior are intentionally unchanged from V2.44.

## Public editions

- **ATN STANDARD** - normal WebExtension edition for addons.thunderbird.net; no custom Experiment API.
- **GITHUB STANDARD** - the same STANDARD payload for GitHub distribution.
- **GITHUB NATIVE** - deeper integration with Thunderbird's built-in Calendar through the custom `nativeCalendar` Experiment API.

## Release engineering changes

- Generalized version and package checks; no release checker is hard-coded to V2.44.
- Expanded public-repository hygiene checks for private build labels, organization mailboxes, GUID-like tenant/application identifiers, provider-specific deployment material and local/chat build paths.
- Added `tools/release_audit.py` as the canonical one-command public QA gate.
- Added deterministic public release/source archive generation.
- Added canonical GitHub/ATN listing and reviewer text in `PUBLISHING.md`.
- Added robust repository update/recovery packaging with backup, managed-tree replacement and SHA-256 verification in the distributed update package.
- Added a final worker-audit prompt to the master release package for independent post-build verification.

## ATN status

The ATN artifact is STANDARD and contains no `experiment_apis` entry and no `experiments/` directory. The NATIVE edition is GitHub-only while Thunderbird's current review policy rejects new submissions using unsupported custom Experiment APIs.

## Compatibility

- Add-on version: `2.0.45`
- Display release: `V2.45`
- Minimum Thunderbird: `128.0`
- ATN STANDARD: no `strict_max_version`
- GitHub NATIVE: no artificial maximum version; ESR remains recommended for production use because the Experiment API depends on Thunderbird internals.

# M365 Calendar for Thunderbird V2.44

V2.44 changes the public distribution model after the V2.43 ATN NATIVE submission was rejected under Thunderbird's temporary pause on new custom Experiment API submissions.

## Public editions

- **ATN STANDARD** — Experiment-free store edition for addons.thunderbird.net.
- **GITHUB STANDARD** — same STANDARD runtime for direct GitHub distribution.
- **GITHUB NATIVE** — deeper Thunderbird Calendar integration through the custom `nativeCalendar` Experiment, distributed through GitHub only.

## ATN STANDARD limitation

ATN STANDARD intentionally does **not** register Microsoft 365 calendars in Thunderbird's built-in Calendar view. Users work with the add-on's Microsoft 365 Space and Graph-backed event/meeting actions. The deeper native Calendar provider is available only in GITHUB NATIVE.

## Build and review hardening

- ATN_STANDARD is built from the exact human-readable STANDARD source with no manifest/source transformation.
- No minification, obfuscation, transpilation, template compilation or JavaScript bundling is used.
- The ATN XPI contains no `experiment_apis` entry and no `experiments/` directory.
- GitHub CI runs the current official Thunderbird `webext-linter` against the ATN_STANDARD artifact.
- Public hygiene checks reject organization-specific OAuth defaults, private deployment material and provider-specific routing documentation.

## Compatibility

- Add-on version: `2.0.44`
- Display release: `V2.44`
- Minimum Thunderbird: `128.0`
- ATN STANDARD: no `strict_max_version`
- GITHUB STANDARD: no `strict_max_version`
- GITHUB NATIVE: no artificial `strict_max_version`; ESR recommended

No intentional Graph/calendar runtime behavior changes were introduced relative to V2.43.

# Contributing

**Maintainer:** Jens Kowalsky

Contributions are welcome through issues and pull requests.

1. Keep STANDARD free of privileged Experiment APIs.
2. Keep NATIVE changes isolated where practical.
3. Do not commit tenant-specific Client IDs, tenant names, company domains, OAuth tokens, secrets, profile data, or exported calendars.
4. Run `python tools/run_tests.py` and `python tools/neutrality_check.py` before submitting a pull request.
5. Keep DE/EN user/admin documentation synchronized when behavior changes.
